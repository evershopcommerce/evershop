# create-storefront-app

The global command for scaffolding a new [Storefront](https://github.com/nttare0/storefront) project.

## Usage

```bash
npx create-storefront-app my-store
cd my-store
npm run setup
npm run dev
```

See the [repository README](https://github.com/nttare0/storefront#readme) for
requirements, configuration and development guides.
